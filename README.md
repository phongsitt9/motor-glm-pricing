# Motor GLM Pricing Project

Personal auto insurance pricing using Generalized Linear Models (GLM)
with the French Motor Third-Party Liability dataset (677,991 policies).

## Notebooks
- 01_data_prep.ipynb — Load & clean data
- 02_eda.ipynb — Exploratory analysis
- 03_burning_cost.ipynb — Burning cost calculation
- 04_glm_model.ipynb — Poisson & Gamma GLM
- 05_results.ipynb — Rate relativities & findings

## Tools
Python · statsmodels · pandas · matplotlib · Google Colab
